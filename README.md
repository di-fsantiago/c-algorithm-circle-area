# c-algorithm-circle-area
**Calculadora da Área de um Círculo**

Aplicação em C para fazer o cálculo da área de um círculo.

## 02. Tecnologias Utilizadas
- C18

## 03. Como Instalar e Executar
Executar através de **IDEs** instaladas na sua máquina ou de compiladores on-line, como o [OneCompiler](https://onecompiler.com/).

## 04. Exemplo de Uso ou Demonstração
Utilizando como exemplo, o valor raio = 5.
```
Digite o raio: 5
A área é aproximadamente = 78.54
```
